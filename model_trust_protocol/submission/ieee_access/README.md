# IEEE Access — Submission Package

This directory contains the publication-ready **IEEE Access** journal submission package generated from the official template (`ACCESS_latex_template_20260513-1-1.zip`).

## Package Structure

| File / Folder | Description |
|---|---|
| `IEEE_Access_manuscript.tex` | **Main LaTeX manuscript source**, fully formatted with IEEE Access double-column styling, equations, tables, figures, and author profile |
| `IEEE_Access_manuscript.pdf` | **Typeset submission PDF** (9 pages, IEEE Access format) |
| `references.bib` | Complete BibTeX database containing all 29 cited works with DOIs |
| `ieeeaccess.cls` | Official IEEE Access document class with compatible color profiles |
| `IEEEtran.cls` | IEEE Transactions base document class |
| `IEEEtran.bst` | IEEEtran BibTeX style file for numbered citations |
| `figures/` | Publication figures, 400 dpi, generated by the reproduction package |
| `*.png`, `*.pfb`, `*.tfm`, `*.fd`, `*.map` | Official IEEE Access font metric and template assets (logos, bullets, author templates) |

## Compilation

To compile the manuscript from the repository root:

```bash
python3 scripts/build_access_tex.py
# or
make access
```

This invokes `tectonic` to produce `IEEE_Access_manuscript.pdf`.

## Document Compliance & Verification

- **Format:** IEEE Access 2-column layout with official Pantone 3015 C branding (`accessblue`)
- **Abstract:** Structured single-paragraph summary (within the 150–250 word IEEE limit)
- **Keywords:** Alphabetical indexed terms aligned with IEEE taxonomy
- **Equations:** Equations (1)–(4) set in display math mode with proper mathematical typography
- **Tables:** Tables 1–4 set to full column width (`tabularx`) with notes aligned to the table rules
- **Authors:** four authors, single affiliation, IEEE Access `\authorrefmark` format; running head is `Singh et al.`
- **Typesetting:** Zero unresolved citations, zero undefined references, and no overfull boxes beyond those the `ieeeaccess` class itself produces
- **Figures:** Figures 1–11 included with full captions; every figure is cited in text
- **References:** 29 references, all cited and all defined; proper nouns brace-protected against `IEEEtran.bst` case folding

> **Note for `ieeeaccess.cls`:** inline math inside `\textbf{}` in a `tabularx` cell raises `Extra }, or forgotten $` under this class. Keep table headers free of `$...$`.
- **Provenance Discipline:** All empirical numbers adhere to the `convgap verify` audit trail

## Outstanding before submission

Two items are deliberately left for the author; both are marked as `TODO BEFORE
SUBMISSION` comment blocks immediately above `\section*{Acknowledgment}` in the
manuscript source. Neither renders in the PDF.

1. **Data and code availability statement.** IEEE Access's reproducibility
   initiative awards *Code Available* / *Code Reviewed* badges for artifacts
   deposited with a persistent DOI and versioning. This repository has no git
   remote and the manuscript names no repository. A commented scaffold is in
   place: state what can be shared (derived artifacts, digests, extractor code)
   versus what cannot (the raw depository record), with a live URL or DOI.
2. **Data access basis.** The acknowledgment thanks "data depository
   administrators" without saying on what basis the proprietary FII settlement
   data was obtained. Combined with the `\tfootnote` no-funding declaration and
   the institutional affiliation, this is a live question for an editor's
   COI/ethics screen. One line resolves it; check it for consistency against
   the funding footnote.

## Terminology

Level 1 is labelled **Persistence**, not Replication. The test asks whether an
effect estimated on the training era holds on a frozen later era drawn from a
shifted cross-section (441 of 1,028 instruments common). That is out-of-sample
persistence under a single research design, strictly weaker than replication in
the credibility literature's sense. `scripts/build_figures.py` carries the same
label, so `figure_2_attrition.png` must be regenerated if it is changed again.
